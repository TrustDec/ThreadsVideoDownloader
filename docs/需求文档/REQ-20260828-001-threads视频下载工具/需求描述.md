## 需求背景

当前下载 Threads、抖音、X 公开视频需要手动打开网页、解析帖子并保存媒体文件。需要提供一个 Mac 本地小工具，让用户粘贴社交平台分享链接后即可自动下载视频。

## 需求范围

- 支持 `threads.com` / `threads.net` 的分享链接、帖子链接，`v.douyin.com` / `douyin.com` 的分享链接、视频链接，以及 `x.com` / `twitter.com` 带数字帖子 ID 的公开状态链接。
- 提供简洁的本地界面：输入链接、开始下载、显示状态和保存位置。
- 下载公开视频为 MP4，自动保存到用户选择的目录。
- 解析到多档清晰度时列出分辨率和码率，由用户选择后再下载；默认勾选最高档。
- 自动生成不易冲突的文件名（含所选分辨率），并保留失败原因。
- 不保存 Threads、抖音或 X 账号密码，不处理私密或必须登录才能访问的内容。

## 非目标

- 不绕过登录、验证码、权限控制或付费限制。
- 不实现批量账号管理、内容发布、评论、点赞等社交操作。
- 不保证第三方媒体解析服务长期可用；解析接口失败时需给出可理解的错误提示。

## 当前结论
