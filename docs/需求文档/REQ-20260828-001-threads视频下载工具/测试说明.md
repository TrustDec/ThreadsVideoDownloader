# 测试说明

## 测试环境

- macOS arm64
- macOS 13+ 目标版本
- Apple Swift 6.3.3

## 自动化验证

在仓库根目录执行：

```bash
swift test
```

结果：7 个测试全部通过，覆盖 Threads / 抖音 / X 链接校验、非 HTTPS/非支持域名/无帖子 ID 拒绝、带分辨率文件名、从媒体 URL 解析宽高，以及清晰度排序与最接近档匹配。

## 构建验证

```bash
./build_app.sh
```

结果：成功生成 `build/Threads视频下载器.app`，应用二进制为 arm64 Mach-O，Info.plist 配置完整。

## 抖音真实链接验证

使用用户提供的公开链接 `https://v.douyin.com/Hk_dx8CV7Js`：

- 短链解析结果：成功定位到抖音视频页 `https://www.douyin.com/video/7678685061026357669`
- 媒体解析结果：成功返回 1 个带音频 MP4 视频地址
- 文件级验证：成功下载并通过 `ffprobe` 检查，H.264 + AAC，1080×1920，约 89.5 秒，约 27.9 MB

## X 真实链接验证

使用用户提供的公开链接 `https://x.com/jeremyjudkins_/status/2096370988728369381?s=46`：

- 解析结果：`api.fxtwitter.com/status/{id}` 返回 1 个视频，最高档为 1920×1080 MP4
- 回退接口：`api.vxtwitter.com/status/{id}` 同样返回同一 1080p 地址
- 文件级验证：已保存到本机“下载”目录 `x_2096370988728369381.mp4`，`ffprobe` 为 H.264 + AAC，1920×1080，约 694.7 秒，约 594 MB

## 真实链接验证

使用公开链接 `https://www.threads.com/share/BBd0VIsOZn/` 调用解析接口：

- 解析结果：成功
- 视频数量：1
- 下载结果：成功保存 MP4
- 文件参数：H.264 + AAC，1280×590，约 63.6 秒，约 6.8 MB

## 清晰度选择验证

- Core：同一视频 1920×1080 / 1280×720 / 640×360 会按从高到低列出；给第二视频只有 640×360 时，选 720p 会分别匹配 1280×720 与 640×360。
- 界面：X 多档帖子解析后弹出单选列表；取消后不下载；选择后按该档保存，文件名含分辨率。

## 人工验证

- 已启动 `build/Threads视频下载器.app`，进程正常运行。
- 界面包含 Threads / 抖音 / X 链接输入、开始下载、选择目录、打开下载目录、进度条和状态提示。
- 多档清晰度时弹出分辨率列表，可改选后再下载；取消后不开始下载。

## 未完成项与风险

- 解析依赖公开第三方服务；私密、登录可见、已删除或无视频资源的帖子无法下载。
